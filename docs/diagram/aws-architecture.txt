Product: portfolio   (example: 2 microservices: webstore, yourOtherService)
Naming convention: ${Environment}-${ProductName}-${AppServiceName}-<resource>
Stack naming convention: <env>-<product>[-<service>]-<layer>

================================================================================
SHARED  (deployed ONCE per environment — used by both services)
================================================================================

CloudFormation stack: dev-portfolio-vpc                         [aws-vpc-stack.yml]
│
└─ Networking
    ├─ VPC (10.0.0.0/16)
    ├─ Internet Gateway  → attached to VPC
    ├─ Public subnets (A, B)  → Public route table → IGW
    ├─ Private subnets (A, B) → Private route table → NAT Gateway
    ├─ NAT Gateway  → sits in Public subnet A
    ├─ Security group: ALB  → allows 80 from 0.0.0.0/0
    └─ Security group: ECS  → allows 8080 from ALB security group only

CloudFormation stack: dev-portfolio-ecs-infra                    [aws-ecs-infra-stack.yml]
│
└─ Shared compute + load balancing
    ├─ ECS Cluster (dev-portfolio-cluster)                      ← shared by every service's tasks
    ├─ Application Load Balancer  → internet-facing, public subnets
    └─ ALB Listener (port 80)  → default action: 404 fixed response
        (each per-service stack below attaches its own path-based
         ListenerRule: /webstore/*, /yourOtherService/*)

================================================================================
PER SERVICE  (deployed TWICE per environment — once with AppServiceName=webstore,
              once with AppServiceName=yourOtherService. Stack names and every
              resource below are namespaced per service; nothing in this block
              is shared.)
================================================================================

┌────────────────────────────── webstore ──────────────────────────────────────┐

CloudFormation stack: dev-portfolio-webstore-codebuild           [aws-codebuild-stack.yml]  (per service)
│
└─ Build pipeline
    ├─ ECR repository            (dev-portfolio-webstore-repo)
    ├─ CodeBuild log group
    ├─ CodeBuild service role  → ECR push, logs, CodeConnections
    └─ CodeBuild project         (dev-portfolio-webstore-codebuild)
        → GitHub source (webstore repo/path) → docker build → push to ECR

CloudFormation stack: dev-portfolio-webstore-iam                 [aws-iam-stack.yml]        (per service)
│
└─ IAM
    ├─ ECS Task Execution Role  → pulls image from ECR, writes logs, reads the DB secret (GetSecretValue)
    └─ ECS Task Role            → app's own runtime permissions (logs; extend as the app needs)

CloudFormation stack: dev-portfolio-webstore-rds                 [aws-rds-aurora-stack.yml] (per service)
│
└─ Data tier (private subnets A + B, never public)
    ├─ Secrets Manager secret  (dev-portfolio-webstore-db-secret)
    │   → generated master credentials (username appuser, 32-char password)
    ├─ DB subnet group         (dev-portfolio-webstore-subnet-group → private subnets A + B)
    ├─ Security group: RDS     (dev-portfolio-webstore-sg-rds → allows 5432 from the ECS security group only)
    ├─ Aurora PostgreSQL cluster  (dev-portfolio-webstore-cluster)
    │   ├─ Serverless v2 scaling: 0.5–2 ACU (defaults)
    │   ├─ Storage encrypted, backup retention 7 days (default)
    │   └─ DeletionPolicy: Snapshot → a final snapshot is taken on delete
    └─ Writer instance         (dev-portfolio-webstore-instance-1, db.serverless)
    Outputs consumed by the service stack: DB_HOST, DB_PORT, DB_NAME, DB_SECRET_ARN

Config (manual step, before the service stack)
└─ SSM Parameter  → /dev-portfolio-webstore-imageTag  (image tag; later written by the pipeline Lambda)

CloudFormation stack: dev-portfolio-webstore-service             [aws-ecs-service-stack.yml] (per service)
│
├─ Compute
│   └─ ECS Service (dev-portfolio-webstore-service)  → runs on the SHARED dev-portfolio-cluster
│       ├─ DesiredCount: 3, MinHealthy: 50%, MaxPercent: 200%
│       ├─ Deployment circuit breaker: enabled, rollback: true
│       ├─ Task 1
│       ├─ Task 2
│       └─ Task 3
│       (tasks get DB_HOST / DB_PORT / DB_NAME from the rds stack; the DB secret is injected from Secrets Manager)
│
└─ Load balancing
    ├─ Target group (dev-portfolio-webstore-tg)  → health check GET /webstore/actuator/health, 30s interval
    └─ ALB Listener Rule  → path /webstore/*  → forwards to dev-portfolio-webstore-tg
                             (attached to the SHARED ALB Listener from ecs-infra stack)

CloudFormation stack: dev-portfolio-webstore-pipeline            [aws-pipeline-stack.yml]  (per service)
│
└─ Auto-deploy trigger
    ├─ EventBridge rule  → fires on "CodeBuild Build State Change" = SUCCEEDED,
    │                       filtered to dev-portfolio-webstore-codebuild only
    ├─ Lambda: dev-portfolio-webstore-deploy-trigger  (Python 3.12, 60s timeout)
    │   ├─ reads IMAGE_TAG from the build's exportedEnvironmentVariables
    │   ├─ describes current task definition (family: dev-portfolio-webstore-task), swaps the image tag
    │   ├─ registers a new task definition revision
    │   ├─ calls ecs:UpdateService on dev-portfolio-webstore-service, forceNewDeployment: true
    │   └─ writes the new tag to SSM /dev-portfolio-webstore-imageTag (source of truth, avoids CFN drift)
    ├─ Lambda execution role  → scoped: logs, dev-portfolio-webstore-codebuild project only,
    │                            ECS describe/register/update on dev-portfolio-webstore-service only,
    │                            the one webstore SSM param, iam:PassRole (ecs-tasks.amazonaws.com only)
    └─ Lambda log group  → /aws/lambda/dev-portfolio-webstore-deploy-trigger, 14-day retention

└────────────────────────────────────────────────────────────────────────────┘

================================================================================
Deploy order
================================================================================
1. dev-portfolio-vpc                (shared, once)
2. dev-portfolio-ecs-infra           (shared, once — imports VPC stack outputs)
3. For EACH service (webstore, yourOtherService), in this order:
   a. dev-portfolio-<service>-codebuild
   b. dev-portfolio-<service>-iam
   c. dev-portfolio-<service>-rds        (imports vpc outputs; exports DB endpoint, port, name, secret ARN)
   d. (manual) SSM parameter /dev-portfolio-<service>-imageTag
   e. dev-portfolio-<service>-service    (imports vpc + ecs-infra + iam + codebuild + rds outputs)
   f. dev-portfolio-<service>-pipeline   (imports codebuild + service outputs)
